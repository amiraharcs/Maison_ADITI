# Maison ADITI: AI Brand Intelligence System

A multi-agent AI system for Maison ADITI, a private UK fine-fragrance house. It is being built during a 4-week EduEmploy micro-placement.

**Agent Zero** is the orchestrator and brand guardian. The owner talks only to Agent Zero, which routes each request to a specialist agent (content, research, SEO, competitor, CRM) and checks that the output stays true to the Maison voice.

## Plan

The work runs as four weekly Scrum sprints, each tracked as GitHub issues:

1. **Sprint 1:** brand knowledge, architecture and Agent Zero v0
2. **Sprint 2:** the priority specialist agents
3. **Sprint 3:** brand-fidelity evaluation
4. **Sprint 4:** digital growth report and roadmap
